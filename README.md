# 🏋️ PULSE Fitness Club

## Gym & Fitness Tracking Web App

PULSE is a responsive gym and fitness web application designed to help users discover workout programs, book group fitness classes, log completed workouts, and track their fitness activity.

The application also includes a staff dashboard for monitoring members, class bookings, check-ins, and gym activity.

## ✨ Features

### 👤 Member Experience

- Browse workout programs
- Filter workouts by fitness goal
- View workout details
- Log completed workout sessions
- Browse group fitness classes
- Book fitness classes
- Track workout activity
- Monitor workout minutes
- View activity history
- Track workout streaks
- Responsive mobile-friendly interface

### 🏋️ Workout Categories

- Strength
- Muscle Building
- Cardio
- Mobility
- Fat Loss

### 📅 Group Classes

Members can explore and book different fitness classes, including:

- Power HIIT
- Strength Lab
- Yoga Flow
- Box & Burn
- Pilates Core
- Cycle Rush

### 📊 Progress Tracking

The My Progress dashboard allows users to monitor:

- Completed workouts
- Workout minutes
- Recent activity
- Fitness streaks
- Overall workout progress

### 🖥️ Staff Dashboard

- Member overview
- Class management
- Booking monitoring
- Gym check-in tracking
- Class schedules
- Fitness activity overview

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Local Storage
- Responsive Web Design
- UI/UX Design

## 💾 Data Storage

PULSE uses browser Local Storage to save demo activity, workout progress, and booking information.

This allows the application to demonstrate persistent data without requiring a backend database.

## 🎯 Project Purpose

This project demonstrates the development of a fitness platform that combines workout discovery, class booking, progress tracking, and gym management tools.

It showcases front-end development, interactive JavaScript functionality, responsive design, data persistence, and dashboard development.
